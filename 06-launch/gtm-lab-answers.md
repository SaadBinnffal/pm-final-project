A valid adoption record may truthfully document an open exception, but it is not a clean completion for task timing. First-use and repeat-use targets apply to newly enabled post-read cohorts, such as former A users. Report already exposed B participants as a separate continuing-beta cohort, with each new cohort clock starting from its own access date. Prior B use is not new activation. Report all starts, failures, exceptions, abandonment, missingness, and account segments. Core Dispatch CSAT must stay at least 4.1/5 without observed deterioration against comparable evidence, and required-record quality and correct completion must not worsen. No new critical validation/false-completion defect is acceptable.

- **Bad signal:** Delivered communication but weak first use suggests access, opportunity, findability, or instruction issues. Strong first use but weak repeated use suggests unresolved task burden or trust problems. Faster completers with falling completion/quality require investigation. These are diagnostic leads, not proven causes.
- **Most likely conditional decision:** Iterate if first use is healthy but repeat use or task value is weak. Change one diagnosed variable and start a fresh measurement window. Double-down only on sustained benefit with quality and sufficient evidence. Investigate/pause for harm or unreliable data. Pivot or deprioritize when adequate evidence challenges the intervention.
